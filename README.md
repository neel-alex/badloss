# MAP-D for backdoor attack detection

An extension of [***Metadata Archaeology: Unearthing Data Subsets by Leveraging Training Dynamics***](https://arxiv.org/abs/2209.10015) for detecting backdoor attacks.

## Execution

The code can be executed using the ```python mapd_backdoor.py <dataset name>``` script provided.
